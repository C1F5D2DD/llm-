# AutoXXT

学习通（超星 chaoxing）网页版的自动化：**多模态大模型看图决策 + Edge 调试协议（CDP）后台操控**。

不移动真实鼠标、不需要窗口可见或获得焦点——挂机时可以一边让它跑，一边干别的，
甚至把浏览器窗口藏到屏幕外。

> ⚠️ 仅供技术学习与个人研究。自动化操作学习通可能违反平台服务条款，风险见文末。

## 特性

- **后台操作**：截图、点击、滚动、打字全走 CDP，不抢鼠标键盘。
- **模型看图决策**：每步发「上一屏 + 当前屏」两张截图，动作生效与否由模型自己对比判断。
- **纯坐标点击**：截图上直接叠坐标网格，模型读出坐标即点。
- **结构化状态反馈**：程序额外报「已勾选数 / 选中态 / 可见弹窗 / 内部滚动」等事实，供模型参考。
- **稳定性机制**：页面跑偏自动切回、ask_human 自动重试、无进展看门狗、重复动作提醒、网络超时自动重发。
- **容错**：空正文重试、畸形 JSON 自动修复、启动失败落盘日志。
- **流式显示**：模型的思考和正文实时滚进对话区。

## 文件

| 文件 | 作用 |
|---|---|
| `pageCapture.py` | CDP 截图，图上叠坐标网格（后台抓帧线程） |
| `window_control.py` | CDP 输入：点击 / 拖动 / 滚动 / 打字 / 按键，页面状态查询，窗口挪动 |
| `brain.py` | 决策：把截图交给多模态模型，拿回一个动作；维护对话历史与日志 |
| `run.py` | 图形界面：左边实时画面 + 控制面板，右边对话区 |

运行产物（不提交）：`runs/brain.log`（完整决策日志）、`runs/startup_error.txt`（启动异常）。

## 快速开始

```bash
conda create -n autoxxt python=3.11 -y
conda activate autoxxt
pip install -r requirements.txt
python run.py
```

`run.py` 会自动启动带调试端口的 Edge（专用用户目录 `edge/`，登录态存在里面，**只需登录一次**）。

然后：

1. 左侧填 `接口地址 / 密钥 / 模型`，选「思考强度」，点「保存配置」；
2. 右侧对话区发一句目标，比如：
   - `帮我把 Python 那门课的课程视频依次看完`
   - `继续完成剩余任务点，阅读任务点到“去阅读”后等 10 秒再回来检查时长`
3. 模型开始连续跑：每一步的思考、动作、结果都会滚进对话历史，左侧画面同步刷新。

跑的过程中随时可以：

- **停止**：当前这步执行完就停（网络请求无法打断，返回后不再执行）；
- **发消息插话**：排队带到下一步（`wait` 等待中会立刻打断并处理你的话）；
- **清空**：清空对话历史和模型上下文。

一个回合默认最多 50 步（界面「最大轮数」可改），单次等待上限 600 秒。

## 界面

- **左栏**：实时画面（网格）、模型配置（接口/密钥/模型/思考强度/最大轮数）、点击与滚动测试、刷新按钮、「显示浏览器窗口」开关。
- **右栏**：对话区 + 发送 / 停止 / 清空。

对话前缀：`AI`=模型想法，`▸`=动作，`✓`=执行结果，`■`=回合结束，`✗`=出错，`?`=模型求助，`·`=提示。

## 配置模型

任何 **OpenAI 兼容**接口都行，三项配置在左侧填写。

**接口地址只填到版本号那一层，不要带 `/chat/completions`** —— OpenAI 库会自己接上，
多填会拼成两遍导致 404（程序会自动去掉并记一条警告，但填对最省事）。

| 服务 | 接口地址 | 说明 |
|---|---|---|
| 智谱 BigModel | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-flash` 免费 |
| 深度求索 | `https://api.deepseek.com` | |
| 硅基流动 | `https://api.siliconflow.cn/v1` | |
| OpenRouter | `https://openrouter.ai/api/v1` | 免费模型每天限量 |

**必须选能看懂图的模型**，纯文本模型跑不起来（每步都要读截图）。

配置存在 `brain.config.json`（含密钥，已在 `.gitignore` 中排除，**不要提交**）。

### 思考强度（reasoning_effort）

服务端认 `none / minimal / low / medium / high / xhigh / ultra / max`，默认 **high**。

- **不要用 `max`**：实测同一道题，max 档想 2.6 万字来回改主意，把输出额度吃光、正文一个字不剩；
  降到 high 后想约 1000 字就答完，结论一样。max 只是"想得更久"，不是"想得更对"。
- 思考**也占用输出额度**（`max_tokens` 默认 16000），额度太小会出现"思考把额度吃光、正文为空"。
- 接口太慢/unstable 时，思考越久越容易撞超时，可降到 `medium` 或换更快的模型。

### 超时与重发

- 连接超时 5 秒；读取超时 30 秒（实测该网关流式分片最长空 14 秒，读取按 5 秒算会中途掐断正常请求）。
- 超时 / 断连 / 5xx / 429 会**自动重发**（最多 6 次，退避 0.4s→2s）；参数/鉴权错误不重发，直接报错。
- 返回空正文会原样重试；JSON 写坏（多引号、漏 `type`）会自动修复后重解析。

## 它是怎么工作的

每一步：

```
截图（带网格）
  → brain.decide(图, 目标, 页面事实, 历史)   # 模型输出 {"thought": ..., "action": ...}
  → run.py 执行动作（点击/滚动/输入/等待/...）
  → 收集执行结果 + 页面状态变化（run.py 的 _facts()）
  → brain.note_result(结果)                  # 回灌给模型，否则它会重复同一个动作
  → 下一步
```

几个关键设计（都是踩坑换来的）：

- **两张图对比**：程序不替模型下"页面有没有变"的结论——它能查的只有地址/滚动/标签页数等，
  页面内部滚动、跨域 iframe、弹窗浮现一概看不见，硬下结论只会误导模型。现在只报原始事实，
  并明确告诉模型"以你看到的两张图为准"。
- **不给元素编号**：早期在可点元素上标红框数字并让模型选编号。但编号每帧都在变
  （滚动、目录展开、弹窗都会让编号重排），上下文里积着旧编号，模型经常拿上一屏的编号点当前屏。
  现在只叠网格，一律用坐标点。
- **不喂页面文字**：学习通有字体加密反爬，DOM 里是生僻字、靠字体渲染成正确的字。
  爬来的文字是错的，喂给模型只会带偏——所以只给截图 + 浏览器读出的少量结构化状态。
- **坐标即页面像素**：截图上叠的网格就是页面坐标，模型读多少就填多少，代码不做任何换算。

## 稳定性机制

| 机制 | 行为 |
|---|---|
| 页面跑偏保护 | 每步开始前检查页面；被误点到「超星智能体」页/学校站点等陷阱页时，自动导航回最近的学习页并告知模型 |
| 学习页优先 | 多标签页时截图/操作永远优先 `studentstudy` 学习页，其次其它学习通页面 |
| ask_human 自动重试 | 模型求助后 5 分钟自动发一次「继续」，最多 3 次；你发消息/点停止即取消 |
| 无进展看门狗 | 连续 12 步无任何可观测状态变化 → 提醒模型换做法；30 步 → 判定卡死并停下 |
| 重复动作提醒 | 同一动作（坐标取整到 10px）重复 15 次提醒、40 次停下；滚动/翻页放宽到 40/120 |
| 回合上限 | 每回合最多 50 步（可调），防止模型停不下来 |
| 启动容错 | 找 Edge 进程不依赖 `tasklist`（受限环境会 Access denied）；拿不到窗口句柄也能纯 CDP 跑；启动异常写入 `runs/startup_error.txt` |

## 坐标约定

截图叠了一层坐标网格：**每 100px 一条深色主线并标数字，中间每 20px 一条淡色细线**。
读法：先找目标最近的主线数字，再数中间隔了几条细线（每条 20px）。例如目标在 `200` 右边第 2 条细线 → `x = 240`。

点击坐标就是浏览器页面坐标（CSS 像素），**不需要做任何加减**。

页面尺寸由 `run.py` 的 `VIEW_W / VIEW_H`（默认 1080×720）决定，网站会按这个尺寸排版。

## 作为库使用

```python
import pageCapture as cap
import window_control as wc
import brain

wc.init(pid)                     # 输入通道（pid 可为 None：纯 CDP 模式）
cap.init()                       # 截图通道（内部起后台抓帧线程）
brain.init(base_url="https://api.xxx.com/v1", api_key="sk-...", model="qwen-vl-plus")

img = cap.get_frame()            # 最新一帧（已叠网格），几乎不耗时
d = brain.decide(img, goal="进入我的课程列表",
                 page=wc.page_info(), frame_age=cap.frame_age())
wc.click(d.action["x"], d.action["y"])
brain.note_result("已点击 (400, 300)")   # 重要：把结果告诉模型

wc.type_text("要输入的内容")      # 在当前焦点输入（支持中文）
wc.press_key("Enter")            # 按键，支持组合键（Control+a 全选）
wc.scroll(3, x=900, y=400)       # 在指定区域滚动
```

`cap.get_frame()` 不阻塞——后台线程一直在抓帧，它只是取现成的。
界面循环里可以先用 `cap.has_frame()` 判断首帧是否就绪。

## 常见问题

**连不上 9222 端口？**
Edge 必须带 `--remote-debugging-port` 启动，并且要用**独立的 `--user-data-dir`**——普通 Edge
已在跑时，带同样参数再启动只会把标签页丢给旧实例然后退出，端口根本不开。`run.py` 已处理好。
手动启动示例：

```bash
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" ^
  --remote-debugging-port=9222 --user-data-dir="edge" https://v8.chaoxing.com/
```

**双击 run.py 没反应 / 窗口打不开？**
先看 `runs/startup_error.txt`（启动异常会写进去）。常见原因：有残留 `msedge.exe` 占着 `edge/`
目录导致 Edge 启动超时——任务管理器里结束所有 `msedge.exe` 再试。

**为什么用 CDP 而不是 Win32 截图？**
Win32 `PrintWindow` 快，但要求窗口可见——被遮挡或挪到屏幕外就截出黑图/旧帧。
CDP 截图稍慢（40–70ms），但**不依赖窗口可见性**：窗口挪到 -32000 后截图照常更新、点击也正常，
所以「显示浏览器窗口」开关可以放心关掉。唯一要注意的是窗口隐藏后滚轮事件可能收不到回执，
`window_control.scroll()` 会自动退化成直接改 DOM 的 `scrollTop`。

**模型总是点偏？**
网格采样误差是这类方案的固有代价。优先让模型"点目标中心、点偏了先微调"，并保证文字/图标
显示清晰；也可以把页面尺寸调大（`VIEW_W/VIEW_H`），目标相对更大更清楚。

**日志在哪？**
`runs/brain.log`：每次请求的提示词、原始返回、解析结果、执行结果都在里面。
